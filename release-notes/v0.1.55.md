# Vyges suite v0.1.55

_Released 2026-11-10 (UTC). Changes since v0.1.53._

Engines are correlated against OpenROAD at [`4155ac310149`](https://github.com/The-OpenROAD-Project/OpenROAD/commit/4155ac31014923e0fa721b691d222511adc7d8c3) (nightly-4155ac310149, 2026-11-03).

CLI binaries and installers: [release v0.1.55](https://github.com/vyges-tools/cli/releases/tag/v0.1.55).

## Install

[vyges.com](https://vyges.com) - full guide: [docs.vyges.com/installation](https://docs.vyges.com/installation.html)

```bash
# this release (macOS / Linux)
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/vyges-tools/cli/releases/download/v0.1.55/vyges-installer.sh | sh
# or: brew install vyges/tap/vyges

vyges install loom       # the Vyges Loom engines
vyges --version && vyges modules
```

Already installed: `vyges update`, then `vyges install loom` to refresh the engines.
